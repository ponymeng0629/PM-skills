# PM Agent Blueprint

把 Agent 当作受控业务系统，而不是一段 Prompt。

## 判断是否应该使用 Agent

比较规则自动化、搜索、Copilot、受监督 Agent 和自主 Agent。选择能实现目标的最低自治级别。

## Agent 契约

定义：

- 用户目标与完成条件；
- 可做、不可做和需要确认的动作；
- 任务状态与中断恢复；
- 工具输入输出、权限、幂等、错误和回滚；
- 知识来源、权限、时效和引用；
- 会话记忆、长期记忆及删除规则；
- 模型失败、工具失败和证据冲突时的处理。

## 人机协同

对不可逆、高影响、权限变化、外部沟通、财务或合规动作设置确认。确认页面必须展示将执行的动作、对象、关键参数和可取消方式。

## 评测

建立覆盖常见、长尾、歧义、无权限、旧数据、工具失败和对抗输入的测试集。分别衡量任务完成、工具正确、知识有据、安全、时延、成本和人工接管。

## 上线

定义试点用户、流量限制、监控、Badcase 复盘、止损、回滚和责任人。平均分不能掩盖严重安全或权限错误。

## 输出

交付机会判断、Agent 状态图、工具与知识契约、确认点、评测表、埋点、上线计划和未决风险。
